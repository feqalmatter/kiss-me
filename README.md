# kiss-me

`kiss-me` is a small Rust mod enabler for game folders that can be assembled
from a vanilla source directory plus a flat mod library. It keeps the original
scriptable command set and adds an interactive terminal UI for enabling mods,
running commands, and watching command output.

The defaults are still aimed at Cyberpunk 2077 installed through Heroic, but the
configuration file supports named profiles so other games or alternate setups can
be added without changing the code.

## Build

```sh
cargo build --release
```

The compatibility `kiss-me.sh` launcher will run `target/release/kiss-me`,
`target/debug/kiss-me`, or `cargo run` in that order.

## Quick start

```sh
# Write ~/.config/kiss-me/config.toml if it does not exist.
kiss-me init-config

# Start the TUI.
kiss-me

# Or run commands directly.
kiss-me extract-downloads
kiss-me enable "Some Mod"
kiss-me assemble
```

## Commands

```text
tui                 launch the terminal UI
config-path         print the resolved config path
init-config         write a starter config
assemble            build a fresh modded game directory
extract-downloads   unpack archives from Downloads into Library
enable <mod>        enable a mod package
disable <mod>       disable a mod package
check-library       check enabled mod directory structure
generate-overwrite  pack local game changes as an overwrite mod
save-manifest       record the current modded game state
diff-manifest       show changes since the saved manifest
remove-readmes      remove top-level .txt files from mod packages
download <nxm-url>  download a Nexus Mods manager link into Downloads
```

Running `kiss-me` with no command opens the TUI.

## TUI controls

- `Tab`: switch focus between the mod list and command buttons
- `Up`/`Down` or `k`/`j`: move selection
- `Space`: enable or disable the selected mod when the mod list is focused
- `Enter`: run the selected command button
- `r`: refresh the mod list
- `q` or `Esc`: quit

The TUI includes a `Download nxm:// link` command. Paste the link when prompted
and press `Enter`.

## Config

By default `kiss-me` looks for config in this order:

1. `--config <path>`
2. `KISS_ME_CONFIG`
3. `./kiss-me.toml`
4. `~/.config/kiss-me/config.toml`

Starter config:

```toml
active_profile = "default"

# Optional. You can also set NEXUS_API_KEY or NEXUSMODS_API_KEY.
# nexus_api_key = "..."

[profiles.default]
game_source = "~/Games/Heroic/Cyberpunk 2077"
library = "./Library"
downloads = "./Downloads"
output = "~/Games/Heroic/Cyberpunk 2077.modded"
manifest = "./.manifest"
nexus_game_domain = "cyberpunk2077"
```

Use `--profile <name>` to run a command against a non-active profile. The
environment overrides from the shell version still work:

- `GAME_SOURCE`
- `LIBRARY`
- `DOWNLOADS`
- `OUTPUT`
- `MANIFEST`
- `NEXUS_GAME_DOMAIN`

## Nexus Mods downloads

`kiss-me download 'nxm://...'` parses Nexus manager links, reads the `key` and
`expires` values from the link, asks the Nexus Mods API for download mirrors, and
streams the selected mirror into the active profile's Downloads directory.

You need a Nexus Mods API key via `nexus_api_key` in config or `NEXUS_API_KEY`.
Non-premium downloads generally require using the `nxm://` link generated by the
website's "Download with manager" button because that link supplies the temporary
`key` and `expires` values.

## Library layout

Each mod is a directory under `Library`. Enabled mods use their normal directory
name; disabled mods end in `.disabled`.

An enabled mod is expected to contain at least one known game root:

- `archive`
- `bin`
- `r6`
- `red4ext`
- `engine`
- `mods`

`assemble` creates a fresh output directory by copying the vanilla game with
`cp -a --reflink=auto`, then overlays enabled mods in sorted order. The output
parent must be on a reflink-friendly filesystem (`btrfs`, `zfs`, `xfs`, or
`bcachefs`) to preserve the original safety guard.
